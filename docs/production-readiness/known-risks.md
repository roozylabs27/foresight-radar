# Known Risks — Foresight Radar

Production readiness remediation, 2026-11-13. Base commit `main` `81fa161`; the changes of this pass are not committed yet (see [final-verification-report.md](final-verification-report.md)).

"Blocks" means: blocks the first controlled organisation (C), or blocks a public launch (P). Severity: Critical, High, Medium, Low.

## Not a risk any more (fixed in this pass)

- **SEC-PR-01 (was Critical):** the AI connection test sent the platform AI key to any base URL a signed-in user typed.
- **SEC-PR-02 (was High):** user-supplied AI base URLs could point at internal addresses (SSRF).
- **SEC-PR-03 (was High):** an organisation admin could demote or remove a platform operator in the organisation.
- **OPS-PR-01 (was High):** a deploy dump and the cron dump running together deleted each other's `.partial` file, and there was no free-space check or stored checksum.
- **DEP-PR-01 (was High):** a manual deploy (`workflow_dispatch`) deployed `main`'s HEAD without proof that CI passed for it.
- **DEP-PR-02 (was Medium):** no post-deploy health check; previous release not recorded.
- **PI-07 (was High, data integrity):** FIRM periods used the rating's creation date.
- **Symfony advisories:** updated to 7.4.22/7.4.23.
